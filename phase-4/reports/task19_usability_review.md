# Task 19 — First-Time User Usability Review

**Application:** CortexHR Insights Console  
**Review Type:** Simulated independent first-time-user evaluation  
**Deployment:** https://employee-ml-project-bmqoxsbtfvhmxybjyc2npm.streamlit.app/

## 1. Was the application easy to understand?

**Feedback:**

"Yes, I understood the basic purpose of the application pretty quickly. It looks like an HR dashboard where different employee-related activities can be checked in one place. The tabs make it easier to understand what each section is meant for. I didn't need much time to figure out where to start."

## 2. Could you find the employee attrition risk feature?

**Feedback:**

"Yes, I found the Risks section without much difficulty. The employee ID input is straightforward, and the result is displayed clearly. I liked that the application shows a risk percentage instead of just saying whether an employee is at risk or not. However, I would want a little explanation of what a particular risk percentage means before making any HR decision."

## 3. Could you use the HR Assistant?

**Feedback:**

"Yes, it works in a way that feels familiar because it is similar to using a chatbot. I can type a question and read the response directly. This is probably one of the easiest sections to use. I would find it useful for quickly checking common HR-related information instead of searching through documents."

## 4. Could you understand the Forecast feature?

**Feedback:**

"Yes, I could understand the forecast results from the table and chart. The model version and training date are useful because they tell me which model produced the results and how recent its training data is. One thing I would appreciate is a short explanation of the lower and upper forecast values because not every HR user may understand prediction intervals."

## 5. Was anything confusing or difficult to use?

**Feedback:**

"Overall, I didn't find the application particularly difficult. However, there are quite a few sections, so a first-time user might need a little time to explore everything. On a smaller screen, navigating between tabs could also be slightly inconvenient. Some technical terms in the results could use short explanations."

## 6. Would you use this application again?

**Feedback:**

"Yes, I would consider using it as an HR dashboard. Having attrition risk, attendance and payroll anomalies, an HR assistant, resume screening and workforce forecasting together is convenient. It saves the effort of switching between different tools. I would still want the results to be reviewed by an HR professional before acting on them."

## Overall Feedback

"After exploring the application, I think it is a useful and reasonably easy-to-understand HR dashboard. The different features are organized well, and the results are presented in a readable format. The assistant and forecast sections are particularly interesting. My main suggestion would be to explain technical results in simpler language so that someone without a technical background can understand them."

## Suggested Improvements

- Add short explanations for technical terms and model scores.
- Explain prediction intervals in the Forecast section.
- Make navigation comfortable on smaller screens.
- Keep human-review warnings visible wherever AI-generated results appear.
- Provide simple guidance for first-time users.

## Review Limitation

This is a simulated first-time-user review based on the deployed application and available interface evidence. It is not a record of an actual external participant interview or independently observed stranger test.
